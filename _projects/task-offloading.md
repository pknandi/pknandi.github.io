- Studied game theory, deep learning, optimization, and meta-heuristic methods for task offloading and resource allocation in cloud computing, with a focus on IoT applications.
- Developed a new algorithm based on **Social Cognitive Optimization**, a meta-heuristic, that finds optimal task offloading policies for energy-harvesting IoT devices.
- Designed and implemented a system that makes computation offloading decisions from IoT devices to the edge cloud, improving user utility and system efficiency.
